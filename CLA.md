Thank you for contributing to komando. This agreement explains what
happens to your contribution. Please read it before you send a pull
request. You sign it in the description of each pull request
(see [How to sign](#how-to-sign)).

- **You keep the copyright** of what you wrote.
- You give the maintainer permission to use your contribution, including
  in the [commercially licensed](COMMERCIAL-LICENSE.md) version of komando.
  This is what keeps komando funded.
- **komando stays open source.** Every contribution will always also be
  available under the AGPL-3.0 or another open-source licence approved by
  the [Open Source Initiative](https://opensource.org/licenses).
- You confirm that you are allowed to give your contribution.

## How to sign

Put this line in the description of your pull request:

```
I have read the CLA Document and I hereby sign the CLA
```

Type it yourself, on a line of its own. Did someone else write commits in
your pull request? Each of them signs in their own words: they write a
comment on the pull request that holds the same sentence. Nobody can sign
for someone else.

A check on the pull request looks for your line and for a comment from every
other commit author. When the pull request is merged, the maintainer adds a
`CLA-Signed-By: <login> (#<number>, <date>)` line to the merge commit for
each signer, so the record stays in git.

Signatures given before 2026-11-23, by a comment to the old bot, are kept
on the `cla-signatures` branch. That branch is never deleted: it is the only
record of those signatures.
